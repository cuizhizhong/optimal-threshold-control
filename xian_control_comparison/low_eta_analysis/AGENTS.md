# AGENTS.md - low_eta_analysis

## 用途

本目录用于西安情景一阈值控制的低阈值压力测试。该实验回答的问题是：

```tex
单纯降低医疗容量阈值 \eta，是否能解决情景一阈值控制启动较晚的问题？
```

该目录是补充数值分析目录，不替代西安主基准结果。西安主基准仍为：

```tex
\eta=0.002N=26326.
```

低阈值长期平台期先作为数值现象保留，不要直接写成“不合理”。它可以解释为长期低感染水平维持或常态化管控的一种数学情形。是否具有现实可行性，需要结合控制时长、清零时间、累计感染和控制成本进一步讨论。

## 核心脚本与方法

主脚本：

- `low_eta_analysis.py`

该脚本复用上一级目录 `xian_control_comparison.py` 中的模型参数、初值拟合结果、TDINN 控制函数和基础汇总逻辑。

情景一阈值控制仍保持为理论推导得到的时间开环控制，不是状态反馈控制。控制律为：

```tex
q_c(t)=1-\frac{\gamma N}{\beta c_0 S_{\rm th}(t)}.
```

为避免极低阈值下平台期过长导致数值积分过慢，脚本在平台期使用解析公式：

```tex
S(t)=\bar S+(S^*-\bar S)e^{-c_0\eta(t-t_1)/N},
\qquad
I(t)=\eta.
```

平台期累计社区感染和累计隔离感染也使用解析积分得到。这样保留了情景一理论控制律，同时可以高效生成低阈值压力测试结果。

## 扫描阈值

敏感性扫描使用的阈值包括：

```tex
\eta\in\{100,300,520,1000,1300,2600,3200,5000,6500,10000,13163,15000,20000,26326\}.
```

其中：

- `eta=100` 是极端低阈值；
- `eta=520` 和 `eta=1300` 是低阈值压力测试点，可对应 ICU 床位数低口径和扩容口径的数量级，但不应直接解释为最终现实社区感染者阈值；
- `eta=26326` 是西安主基准 `eta=0.002N`；
- 其余阈值用于观察从极低阈值向主基准过渡时，控制时长和清零时间如何变化。

代表性面板图使用：

```tex
\eta\in\{100,520,1300,5000,13163\}.
```

## 主要数值结果

根据 `low_eta_summary_20260617_071618.csv`，代表结果为：

| 阈值 \(\eta\) | \(t_1\) | 控制时长 \(\Delta t\) | 清零时间 \(T_{\rm clear}\) | 总累计感染 \(I_{t_{cum}}\) |
|---:|---:|---:|---:|---:|
| 100 | 11.38 | 22523.29 | 23748.32 | 2109306 |
| 520 | 13.01 | 4331.01 | 5027.38 | 2131902 |
| 1300 | 13.91 | 1732.12 | 2233.26 | 2155252 |
| 6500 | 15.51 | 346.04 | 626.30 | 2233778 |
| 15000 | 16.34 | 149.67 | 358.74 | 2307612 |
| 26326 | 16.90 | 85.07 | 258.11 | 2377943 |

主要数值现象是：

```tex
\eta\downarrow
\quad\Rightarrow\quad
t_1\downarrow,\qquad
\Delta t\uparrow,\qquad
T_{\rm clear}\uparrow.
```

也就是说，降低阈值可以提前启动控制并降低峰值，但启动时间提前幅度较小，而控制时长和清零时间会大幅增加。

## 解释边界

该实验的核心解释是：

- 低阈值使系统更早触碰阈值线，因此 \(t_1\) 提前；
- 平台期内要求 \(I(t)=\eta\)；
- 当 \(\eta\) 很小时，平台期内感染者数量低，易感者消耗速度很慢；
- 控制时长公式中存在主导项 \(1/\eta\)：

```tex
\Delta t
=
\frac{N}{c_0\eta}
\log\frac{S^*-\bar S}{S_c-\bar S}.
```

因此，极低阈值会导致平台期和清零时间显著延长。

写分析时不要只看 `t1` 是否提前，也要同时看：

- 控制时长；
- 清零时间；
- 累计感染；
- 隔离强度；
- 成本函数。

## 使用规则

- 不要用本目录结果覆盖 `xian_control_comparison/` 的主基准输出；
- 不要把低阈值长期结果直接写成“不合理”；
- 不要把 `eta=520` 或 `eta=1300` 直接解释为最终现实社区感染者阈值；
- 如果需要完整阈值响应图谱，应新建或使用 `threshold_landscape_analysis/`，不要继续扩大本目录职责；
- 该目录中的图和表主要用于解释“降低阈值的代价”，不是用于最终证明某个策略优于另一个策略。
