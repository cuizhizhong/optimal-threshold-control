## 微分方程定义函数 `daefun`

```matlab
function daefun(daeh,x,z,u,p)
daeh.setODE('Nt', p.r*x.Nt - (u.delta0*x.pt + (1-x.pt)*u.delta1)*x.Nt);
daeh.setODE('pt', p.eta*x.pt*(1-x.pt)*(1-x.Nt/p.ET));
end
```

- 定义 `Nt` 和 `pt` 的微分方程。

```matlab
function pathcosts(ch,x,z,u,p)

ch.add( u.delta0.*x.pt);
end
```

# 代码解释2

## 头部注释



```matlab
%用多重打靶法求解含有纯状态约束的最优控制问题
% min \int_0^{tf} u(t)^2 d(t)
% 满足方程 dS/dt=-(1-u)*beta*S*I; dI/dt=(1-u)*beta*S*I-gamma*I;
% 控制变量约束 0<=u<=1
% 纯状态变量约束 I<=I_{max}
```

- **说明**：  
  - 本问题采用多重打靶法（Multiple Shooting Method）来求解最优控制问题。  
  - 目标函数为最小化积分 \( \int_0^{t_f} \frac{u(t)^2}{2} dt \)（代码中用 \(u(t)^2/2\) 表示），即使控制能量最小。  
  - 状态方程为  
    \[
    \begin{cases}
    \frac{dS}{dt}=-(1-u)\,\beta\,S\,I,\\[1mm]
    \frac{dI}{dt}=(1-u)\,\beta\,S\,I-\gamma\,I,
    \end{cases}
    \]
    这类似于传染病模型（例如 SIR 模型）的变形，其中 \(S\) 与 \(I\) 分别代表易感者与感染者。  
  - 控制约束： \(0 \le u(t) \le 1\)；状态约束： \(I(t) \le I_{max}\)。


- `p.ns = 2; p.nu = 1;`：

## 4. 求解最优控制问题

## 7. 子函数部分

下面介绍三个子函数，这些函数封装了目标函数、状态方程与非线性约束的计算。

### 7.1 目标函数（objfun）

```matlab
function f = objfun(y, p)
    % 得到状态量和控制量
    x = y(p.x_index);
    u = y(p.u_index);
    L = u.^2/2;            % 积分项：控制能量（每个节点上的瞬时代价）
    f = trapz(p.t, L);     % 利用梯形积分公式计算积分值
end
```

- **功能**：  
  - 将决策向量 `y` 中提取出控制变量 \( u(t) \)，计算目标函数值，即积分 \( \int_0^{t_f} \frac{u(t)^2}{2} dt \)。
- **细节说明**：  
  - `u.^2/2`：对每个节点计算瞬时代价。  
  - `trapz`：利用梯形积分公式（trapz）对离散时间点上的代价进行积分，近似连续积分。

### 7.2 状态方程（state_eq）

```matlab
function dy = state_eq(y, u, p)
    dy(1) = -(1-u)*p.beta*y(1)*y(2);
    dy(2) = (1-u)*p.beta*y(1)*y(2)-p.gamma*y(2);
end
```

- **功能**：  
  - 给定状态 `y` 与控制量 `u`，计算系统在该点的状态导数。  
- **说明**：  
  - 与头部注释中给出的模型一致，描述了 \( S \) 与 \( I \) 的相互作用及控制对系统的影响。

### 7.3 非线性约束函数（noncon）

```matlab
function [c, ceq] = noncon(y, p)
    % 得到状态量和控制量，并将其重塑为矩阵（每行对应一个打靶节点）
    x = reshape(y(p.x_index), [], p.ns);
    u = reshape(y(p.u_index), [], p.nu);
    
    % 计算每个子区段内的时间步长
    h = p.tf/(p.N-1)/(p.M-1);
    
    % 初始化用于存储各区段末端状态的矩阵
    states_at_nodes = zeros(p.N, p.ns);
    for i = 1:p.N-1
       x0 = x(i,:);   % 当前打靶节点的状态
       u0 = u(i,:);   % 当前区间内使用固定控制量（多重打靶法中在区段内保持常值）
       states = zeros(p.M, p.ns);
       states(1,:) = x0;
       % 在当前子区段内采用四阶 Runge-Kutta 方法进行状态积分
       for j = 1:p.M-1
           k1 = state_eq(states(j,:), u0, p);
           k2 = state_eq(states(j,:) + h/2 .* k1, u0, p);
           k3 = state_eq(states(j,:) + h/2 .* k2, u0, p);
           k4 = state_eq(states(j,:) + h * k3, u0, p);
           states(j+1,:) = states(j,:) + h/6 * (k1 + 2*k2 + 2*k3 + k4);
       end
       % 将区段末端的状态存入 states_at_nodes
       states_at_nodes(i+1,:) = states(end,:);
    end
    
    % 构造连续性约束：每个子区段起始状态与前一区段末端状态必须一致
    ceq_temp = x(2:end,:) - states_at_nodes(2:end,:);
    % 同时加入初始条件约束
    ceq_temp = [ceq_temp; x(1,:) - p.x0];
    ceq = reshape(ceq_temp, [], 1);
    
    % 此处无额外的不等式约束（状态约束在变量上界中已体现）
    c = [];
end
```

- **功能**：  
  - 构造多重打靶法中的**连续性约束**，保证分段积分所得的状态与决策向量中对应的打靶节点状态一致。  
- **实现步骤**：  
  1. **提取变量**：  
     - 将决策向量中状态变量与控制变量重塑为矩阵，每行代表一个打靶节点。  
  2. **计算子区段积分步长**：  
     - 每个区间进一步细分为 `p.M` 个小节点，步长 \( h \) 为 \( \frac{t_f}{(N-1)(M-1)} \)。
  3. **区间内状态积分**：  
     - 对于每个子区段，固定区间内控制量 \( u0 \) 后，采用四阶 Runge-Kutta 方法积分状态方程，得到子区段末端状态。  
  4. **构造约束**：  
     - 要求连续性：每个子区段末端状态必须与下一个打靶节点的状态一致；同时，初始状态必须等于给定初始条件 `p.x0`。  
  5. **输出**：  
     - `ceq` 为等式约束，`c` 留空表示无额外的不等式约束（状态约束在边界条件中已体现）。

## 多重打靶法

多重打靶法（Multiple Shooting Method）是一种常用的数值优化方法，用于求解含有约束的最优控制问题，尤其适用于那些无法通过简单的解析方法求解的高维、非线性系统。该方法通常用于解决由常微分方程（ODEs）描述的动态系统，并且能够处理状态变量和控制变量之间的复杂关系。

### 1. **背景与动机**

最优控制问题的形式通常如下：

\[
\min_u \int_0^{t_f} L(t, x(t), u(t)) \, dt
\]

其中：
- \( x(t) \) 是状态变量，通常满足常微分方程（ODE）：  
  \[
  \frac{dx}{dt} = f(t, x(t), u(t))
  \]
- \( u(t) \) 是控制变量，通常需要满足控制约束（例如：\( 0 \leq u(t) \leq 1 \)）。
- 目标是最小化目标函数（例如：控制能量、时间或其他性能指标）。

在很多实际问题中，求解这种最优控制问题是非常复杂的，因为这些问题通常是非线性、动态的，且具有状态约束、控制约束等复杂条件。对于这种问题，**多重打靶法**提供了一种有效的数值解法。

### 2. **基本思想**

多重打靶法的核心思想是将整个时间区间分割为多个子区间（子时间段），然后通过在每个子区间内的数值积分来逐步逼近最优解。具体步骤如下：

#### 2.1 **时间区间的分割**
将时间区间 \( [0, t_f] \) 划分为 \( N \) 个小的子区间，每个子区间的起始和结束时间分别为 \( t_i \) 和 \( t_{i+1} \)（其中 \( i = 1, 2, \dots, N-1 \)）。在每个子区间内，控制变量 \( u(t) \) 被视为常量，且在子区间内进行数值积分。

#### 2.2 **子区间内的数值积分**
对于每个子区间 \( [t_i, t_{i+1}] \)，使用数值方法（如四阶 Runge-Kutta 法、欧拉法等）对系统的常微分方程进行积分，得到每个子区间的状态轨迹 \( x(t) \)。

#### 2.3 **子区间之间的连续性**
在多重打靶法中，关键点是保证子区间之间状态的连续性。每个子区间的终点状态应该与下一个子区间的起点状态匹配。具体来说，对于每个子区间，要求其终点状态与下一个子区间的起点状态一致：

\[
x_{i+1}(t_{i+1}) = x_{i}(t_{i+1})
\]

如果这些状态之间存在不连续性，就意味着我们选择的控制策略不合适，需要通过优化算法调整控制变量，直到状态连续。

#### 2.4 **目标函数和约束**
- **目标函数**：通常是控制变量 \( u(t) \) 的二次或其他形式的积分，表示控制的能量或某种性能指标。
- **约束条件**：包括系统的状态约束（例如，某些状态变量不能超过特定值）、控制约束（例如，控制变量需要在某个范围内），以及状态方程（描述系统的动力学）。

#### 2.5 **优化问题的求解**
多重打靶法通过优化算法（如顺序二次规划法 SQP、内点法等）求解优化问题。在此过程中，优化算法会调整每个子区间的控制策略，确保最终的状态轨迹符合约束条件，并且最小化目标函数。

### 3. **多重打靶法的步骤**

总结起来，多重打靶法的步骤如下：

1. **划分时间区间**：将整个时间区间 \( [0, t_f] \) 分割为 \( N \) 个子区间。
2. **初始化**：为每个子区间选择初始控制策略，并计算对应的状态轨迹。
3. **数值积分**：在每个子区间内，使用数值方法（如 Runge-Kutta）对状态方程进行积分，得到状态轨迹。
4. **连续性约束**：通过优化算法调整控制策略，保证子区间之间的状态连续性。
5. **优化求解**：通过优化算法（如 SQP）最小化目标函数，并更新控制策略，直到满足所有约束条件。
6. **最终解**：得到全局最优控制策略以及对应的状态轨迹。

### 4. **多重打靶法的优势**

- **适用于高维系统**：多重打靶法能够有效处理高维、复杂的最优控制问题，尤其适用于无法通过解析方法求解的问题。
- **灵活性**：可以处理状态约束、控制约束等复杂约束条件。
- **精度较高**：通过细分时间区间并保证每个子区间的精度，能够得到较高精度的解。

### 5. **多重打靶法的挑战与限制**

- **计算量大**：将时间区间划分为多个子区间，意味着需要对每个子区间进行数值积分，计算量较大，特别是当时间步长很小或系统复杂时。
- **求解速度慢**：多重打靶法需要进行多次迭代，每次迭代都要求解一系列的最优化问题，计算开销较大。

### 6. **应用场景**

多重打靶法广泛应用于以下领域：

- **传染病模型**：如优化控制策略（例如疫苗接种、隔离措施等）以减少疾病的传播。
- **生态系统建模**：例如优化捕食者和猎物之间的互动，研究生态平衡。
- **航天与自动控制**：在航天器轨道控制、机器人路径规划等问题中，优化控制输入以达到特定目标。
- **能源管理**：优化能源分配策略以最小化成本或最大化效益。

### 总结

多重打靶法是一种强大的数值优化工具，尤其适用于求解复杂的最优控制问题。通过将时间区间分为多个子区间，并在每个子区间内进行数值积分，能够有效处理系统的动态演化及约束条件，得到最优的控制策略。
