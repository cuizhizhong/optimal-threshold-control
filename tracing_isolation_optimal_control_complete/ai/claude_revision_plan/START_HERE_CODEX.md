# 给 Codex 的执行入口（第二轮修订）

## 开始前

1. 完整阅读 `REVISION_PLAN.md`（v4 合并版）。只有遇到需要细节的步骤时，再查 `REVISION_PLAN_v2_author.md` 和 `SYMBOL_TABLE.md`。
2. 计划中的预期数值只是验收参照，不是已完成的结果。
3. 基准为分支 `codex/numerical-reproducibility-revision` 上的提交 `44112cc` 及其后续提交。
4. 读取 `SYMBOL_TABLE.md` §0，跳过作者标注为"不采纳"的条目。

## 通用规则

- 每一步做成一次独立提交，提交信息写清改了什么、怎么核对的。**不要推送。**
- 每一步完成后都要实际编译论文；改动理论部分时，TheoryOnly 也要编译。
- 已有的原始记录和评估文件不得改写或删除。
- 只有 S2.4 和 E2 两步允许调用优化器；其余步骤必须为 0 次。
- 遇到计划里写明的"停止条件"，立即停下并报告，不要自行放宽标准或绕过。
- 带"作者审阅"标记的步骤：提交初稿后暂停，列出需要作者决定的问题。

## 分批指令

| 批次 | 对应步骤 | 指令 |
|---|---|---|
| 第一批 | S1 | 论文符号定稿：只改名，不改内容。完成 S1.1–S1.4，汇报公式核对结果、编译结果和改名清单 |
| 第二批 | S2 | 代码改名并重跑：先打标签 `pre-code-rename` 并提交改名清单（S2.1），等作者确认清单后再做 S2.2–S2.9。重跑必须实际执行 35 次求解；新旧逐条对比不过关就停 |
| 第三批 | A1 | 五仓室模型改写，并执行符号条目 #1、#2、#5、#6。完成后暂停，等作者审阅模型节 |
| 第四批 | B、C | 重写引言与贡献（作者审阅）；整理两层分区、主结果前置、$\bar q$ 可行域命题、机制说明。C5 可选，单独提交 |
| 第五批 | D 与 E1 | 两者可以并行：量级、渐近与参数来源；回流的前向仿真（不调用优化器） |
| 第六批 | E2–E4 | 低维策略族优化、安全证书、参数失配与设计裕度；完整三维 OCP 只在计划说明的条件下才做 |
| 第七批 | F、G | 数值章节重写；全文定稿（作者审阅）。中文定稿后再统一转成英文 |

## 每批结束时的汇报内容

- 提交号及改动文件清单；
- 实际运行的命令及结果（编译页数、测试数、优化器调用次数、求解次数）；
- 与计划验收参照的差异；
- 遇到的停止条件或需要作者决定的问题。
