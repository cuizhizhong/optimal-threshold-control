## 关键证明及边界核查

- 完全追踪的有限可达条件严格区分 `s*exp(-i/ell)<s_A` 与等号；感染趋零不等于有限时间可永久停控。
- 非平凡切换根的参数域、导数符号、分支拼接、端点极限和唯一容量交点一致。
- 分区覆盖、相对开放性及候选策略的可行达到性不依赖最优性，没有循环使用主定理。
- 有限成本推出有限安全首达的反证涵盖全部可测可行控制，不预设阶段或有限切换。
- 正感染初值使有限时间轨道远离坐标轴；局部梯度估计中的 `1/i` 不妨碍绝对连续复合。
- 容量上的时间集合以绝对连续水平集性质处理，没有把状态空间零测集误当作时间零测集。
- 等号条件先固定分区控制，容量延续和严格横穿再排除其他最优延续，最后逐段应用常微分方程唯一性。
- 核查了 `h+K=1`、`s_B+K=1`、初值已在容量线、临界轨道标签以及安全/容量交点等退化情形。
- 独立重推小容量下一阶系数，公共入口与固定传播概率的条件保持；医疗阈值仍仅是附加核假设下平均需求的充分条件。

本结论是全文主要证明的人工逻辑、代数与有限公式核对结果，不是形式化证明认证。接触率恒定、无易感回流、正初值、固定传播概率等限定仍然必要。
