## 仍需保留的局限与下一步

第 3 节仍是符号最密集的部分；现有导读已降低负担，继续修改应优先补符号解释，并保留第 4–5 节的验证与唯一性细节。小容量结论固定传播概率并要求共同容量入口，不能推广为传播概率趋零时的一致展开，也不能把时长收益解释为隔离人日收益。

本轮形成的是可继续投稿打磨的中文整合稿。未新增外部数据拟合、独立预测检验、优化器实验或全新模型验证；有限数值检查也不能替代全局最优性证明。作者、单位与目标期刊格式仍待投稿阶段填写或调整。
