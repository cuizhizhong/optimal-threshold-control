## 改写规则

1. 句子写完整：有主语、有连接词，不用电报式短句；推理用"先……再……所以……"串成段落。
2. 每个小节开头用一两句话说明本小节要证明什么、为什么需要、后文在哪里用到。
3. 记号引入要有句子交代用途，例如先说"把控制系统写成两个向量场的凸组合"，再给公式。
4. 删除防御性或备忘式的语句；必要的限定改为正面陈述，并且只说一次。
5. 关键结果之后用一句话连接后文，例如指出有限成本比较策略就是第 7.3 小节的纯容量填充。
6. 不改任何数学内容：定理、引理、命题的陈述，带标签和不带标签的公式，以及所有标签都逐字保留；证明的每个逻辑步骤都保留，只调整语序、合并句子、补充连接。
