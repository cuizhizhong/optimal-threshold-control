1 问题来源与建模目标
附件论文研究标准 SIR 约化系统中同一个传播函数同时控制易感者减少和感染者增加的情形，
并以传播函数低于自然水平的幅度作为线性抑制成本 [1]。其核心结果是：若自然传播峰值超过医
疗容量，则最优策略先不控制，在感染首次达到容量时突然加强控制，随后沿容量边界逐步放松，
最后恢复自然传播。该论文还证明最优控制在前两个阶段一致，而若允许传播率无成本地高于自然
水平，则解除控制以后可能出现多重最优延拓。
本文考虑的跟踪隔离机制与上述结构有本质区别。恢复者、隔离易感者和隔离感染者舱室与前

证明. 设 q 是任意最优控制。验证不等式积分后必须取等号，否则其成本严格大于值函数。因此

沿最优轨道几乎处处成立，即 q(t) 必须属于点态 Hamiltonian 极小集。自然等待区和安全集内唯

切换点可能同时允许两个端点或一个区间的点态极小元，但这些时刻测度为零。因此所有最优控制
几乎处处相同。
注 10.2 (唯一性可能失效的精确位置). 线性成本下，非唯一性只可能来自以下退化：
(i) Σ = 0 在正长度内部区间上成立，形成奇异弧；
(ii) 最优轨道沿切换曲线切向滑行；
(iii) 容量边界上 Σ = 0 在正长度区间成立，使 [qB , 1] 中多个控制同时最小。
这些不是由模型代数形式自动产生的普遍现象，而是需要附加等式同时成立的非泛型情形。基准参
数下三个退化均未发生。

10.1 为什么解除隔离以后也唯一
附件单传播系数模型把高于自然传播水平的控制视为无成本，因此在达到群体免疫以后，某些
“加速传播”延拓也可能零成本。当前模型中 q ∈ [0, 1]，且
β2 = pc(1 − q)
只会随着 q 增大而下降；不存在通过 q 把感染生成率提高到自然水平以上的方向。更重要的是，任
何 q > 0 都有严格正成本 pcq。因此进入 A 后，q = 0 不仅可行，而且是唯一零成本控制。这使最
优控制从“解除时刻以前唯一”提升为“全时段几乎处处唯一”。

15 生物学与政策解释
15.1 为什么容量边界后可能需要完全跟踪
在单传播系数模型中，沿容量边界运行会逐渐接近 s = h，此时自然传播恰好不再增长。当前
模型中完全跟踪 q = 1 有两个同时发生的效果：
(i) 新感染生成项立刻降为零，i 以速率 γ 指数下降；
(ii) 被跟踪的易感接触者继续离开未隔离 S 舱室，使状态更快进入无控制安全集。
因此在容量边界上运行到某个内生切换点后，短时完全跟踪可能比继续维持 i = K 更便宜。

15.2 容量不是唯一阈值
系统包含三个不同阈值：
(i) 医疗容量 K：状态可行性阈值；
(ii) 自然传播阈值 h = γ/(pc)：无隔离下感染增长率变号的位置；
(iii) 跟踪几何阈值 r = (1 − p)h：出现在 Φ̇、容量动力学和切换函数中。
最优切换点由 Θ 匹配决定，通常不等于其中任何一个单独阈值。

15.3 唯一性的政策含义
几乎处处唯一意味着：在给定模型、成本、容量和参数下，除孤立切换瞬间外，不存在另一条
成本完全相同但政策强度不同的最优路径。这对政策解释很重要，因为它排除了“任意延后或提前
都一样好”的平坦目标面。另一方面，时变 c(t) 下若切换函数在区间上接近零，数值上会表现为多
条近似等价策略；此时应报告近最优集合，而不应过度宣称单一路径。

16 理论边界与进一步扩展
1. 本文的闭式几何依赖 c 为常数。周期接触、季节性或行为反馈会使值函数显式依赖时间。
2. 线性成本产生 bang–bang 结构和潜在奇异退化。严格凸成本会平滑控制，并使点态极小元唯
一。
3. 若隔离效能不完全，可把 q = 1 时的感染生成系数改为正残余值；端点不变量会改变，但 HJB
与特征线方法仍适用。
4. 若跟踪能力有上限 q ≤ qmax < 1，则完全跟踪段替换为饱和段 q = qmax ，容量可行性还要求
qmax ≥ 1 − h/s。
5. 若 c 和 q 都内生，必须同时建模社交接触成本、跟踪资源成本和政策变化成本。
6. 参数不确定时，可把 p, c, γ 视为区间或随机过程，研究鲁棒状态约束和风险敏感目标。

17 主要结论
本文得到以下结论。
1. 跟踪隔离模型中的 β1 和 β2 虽不同，但不是独立控制；它们由同一个 q(t) 以相反方向耦合。

2. 对固定常数 c，自然传播安全集、容量边界控制、完全跟踪不变量和切换函数都可显式写出。
3. 内部线性 Hamiltonian 决定最优控制只取 0 或 1；唯一中间控制为容量边界强制的 qB =
1 − h/s。
4. 切换曲线沿每条完全跟踪特征线至多有一个非平凡根，因此完全跟踪开始点具有内在唯一性。
5. 在横截性和无奇异弧的可检验条件下，候选反馈满足完整 HJB 验证定理，并在全时间轴上几
乎处处唯一。
6. 基准参数的唯一最优结构为
0 → qB (s) → 1 → 0,
最小成本为 1.5295111602，比纯容量填充低约 3.10%。
7. 对给定时变 c(t)，唯一性不再由自治几何自动保证；线性成本下必须检查时变切换函数，严格
凸正则化则给出唯一投影反馈。
8. 当 c 已知时，q 与 (β1 , β2 ) 一一对应；即使 c 未知，只要两个系数同时可识别，也可由显式公
式恢复 c 和 q。

校验口径

本报告区分三类结论：
(i) 由恒等式、单调性和 HJB 点态极小直接证明的解析结论；
(ii) 在明确横截性假设下成立的全局验证与唯一性定理；
(iii) 仅针对基准参数或参数扫描得到的数值结论。
常接触率基准参数满足横截条件，并通过一维成本二阶差分、切换函数导数、容量误差和独立策略
比较共同校验。时变接触率结果是严格凸正则化后的离散最优解，不把它误述为未正则化连续问题
的闭式唯一解。
