## 新增与改写

- **验证原理**（引理 4.9）分两条：
  - (i) 若在安全集上为零的函数 $Z$ 沿每条有限成本可行轨道绝对连续，且 $\frac{d}{dt}Z(x^q)+\beta cq\ge0$ 几乎处处成立，则 $Z\le V$；
  - (ii) 若某个可行控制的成本恰为 $Z(x_0)$，则 $V\le Z$。

  证明就是原定理 6.7 证明中的那段论证，只是把 $U$ 换成一般的 $Z$；其中"首次到达后成本非负，不要求竞争控制关闭控制"的说明随之移入。
- **注记 4.10** 说明本引理与 MSW 引理 1–2 的关系：
  - 可微性换成沿轨道的绝对连续性。本文的 $U$ 在安全边界上有折角，在容量线上只取内侧梯度。
  - 对任意策略的横截条件，换成有限成本轨道在有限时间进入安全集（引理 4.5）。
  - 比较对象是全部可测控制。

  注记只陈述本文做法，不评论 MSW 的写法。
- **定理 6.7（全局最优性）**：陈述逐字不变；证明改为应用验证原理。条件 (i) 由引理 6.6 加引理 4.5 给出，条件 (ii) 由命题 5.14 给出。
- **第 4 节节首路线**：由三步改为四步，与新结构对应。第 5、6、7 节各加一段节首导言，说明本节在验证原理中的位置。
- **引用更新**：4.4 节导言、4.5 节末尾的引用改为指向新的 4.6 小节和第 7 节。
- **删除**：G1 留下的三处标记注释（`% G1-INTRO-CONSTRUCTION`、`% G1-INTRO-VERIFICATION`、`% G1-TRACKING-PROOF-SKETCH`）和唯一性证明中的 `% G1-UNIQUENESS-ROADMAP`。
