# 阶段 G3 补充：8.3 节正控制时长改为两位小数

基准：`fe09fae`（G3），分支 `codex/numerical-reproducibility-revision`。本地提交，不推送。

## 原因

G3 把 8.3 节的正控制时长统一取到 0.1 后，差值与两端取整值之差相差 0.1：

- "4.8 缩短至 2.2，差为 2.5"，而 4.8 − 2.2 = 2.6；
- "32.5 日缩短至 24.3 日，差为 8.3 日"，而 32.5 − 24.3 = 8.2。

作者决定（2026-10-21）：8.3 节改为两位小数，使差值与两端一致；摘要与讨论保持一位小数。

## 改动

只改导言区宏 `\Dur` 的取整位数（`round-precision=1` → `2`）及其注释。8.3 节的 12 处时长随之变为两位小数：

| 位置 | 改前 | 改后 |
|---|---|---|
| E2 算例 | 4.8、2.2，差 2.5 | 4.77、2.23，差 2.54 |
| 西安情景 | 32.5 日、24.3 日，差 8.3 日 | 32.52 日、24.26 日，差 8.26 日 |
| 时长差的极限与 $K=0.01$ 时的实际值 | 24.3 日、8.3 日 | 24.34 日、8.26 日 |

两组差值与两端之差一致：4.77 − 2.23 = 2.54，32.52 − 24.26 = 8.26。

摘要、讨论与结论使用另一组一位小数的宏（`\DabstractTimeFillZ` 等），仍为"32.5 日缩短至 24.3 日"，且不出现差值。
