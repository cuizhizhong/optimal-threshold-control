## 两处必要的准确表述

1. D包含容量条件i≤K，不能对任意控制正向不变。sum-decay只保证任意允许控制保持s+i≤1；可行控制另外保持i≤K，故可行轨道保持D。正文按此区分，没有把可行性条件误写成全控制不变性。
2. 正文3.10%的分母为对照成本J_fill。解析重算J*=1.5295111601514728、J_fill=1.5783855039561376，(J_fill−J*)/J_fill=3.0964769812%，约3.10%；若说“对照比最优高”并以J*为分母，应为3.19542%，约3.20%。图注采用“相对该对照路径，E2最优成本降低约3.10%”，未改正文数值或分母。
