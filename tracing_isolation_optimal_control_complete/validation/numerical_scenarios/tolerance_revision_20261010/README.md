# 数值接受容差重评，2026-10-10

本轮由作者明确授权提高接受容差。修改发生在原35个配置求解完成之后，是对同一批保存数据的后验重评；不是实验前预定容差，也不是重新优化。

| 接受指标 | 原值 | 新值 | 含义 |
|---|---:|---:|---|
| 状态绝对容差 | 1e-6 | 1e-5 | 用于状态界、初值及配点节点与原控制重积分的差异 |
| 容量绝对容差 | 1e-6 | 1e-5 | 用于重积分容量超出与零控制安全延拓检查 |
| 容量段控制误差 | 2e-3 | 3e-3 | 原分段常数控制与重积分轨道上 q_B 区间均值的最大绝对差 |

成本相对误差容差仍为1e-4。控制边界、成本记账、ODE积分精度、阶段识别阈值、过渡单元数和事件距离判据均未修改。模型参数、容量K、优化问题、数学证明和预定主网格未修改。

K=0.15时，容量容差1e-5为总量比例的0.001个百分点，约为K的0.006667%。E2/E4在N=4000的实际容量超出为3.3392752e-6和3.0908399e-6，分别约为K的0.002226%和0.002061%；N=8000进一步降至7.9910605e-7和7.7028696e-7。E4容量段控制比较误差从N=4000的0.0025306491降至N=8000的0.0012576915。新容差据此作为本问题的浮点接受尺度，不能解释为严格连续可行性证书或收敛阶。
