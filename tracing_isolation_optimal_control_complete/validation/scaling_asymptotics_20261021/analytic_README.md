# D4 解析核算与量级图

本目录计算使用 80 位 mpmath 标量求根、封闭公式与独立标量积分；只有独立总成本差恒等式核对提高到 110 位，以覆盖 O(1/K) 总成本之差为 O(K^2) 的消去。优化器调用、新增 OCP 求解、ODE 求解均为 0。

运行命令：`python tracing_isolation_optimal_control_complete/validation/scaling_asymptotics_20261021/analytic_scan.py`（仓库根目录）。

当前符号为 `beta`、`p=(1-beta)h`、`ell=beta*h`。历史脚本中输入参数 `p` 表示 beta；本脚本未调用旧脚本。

## 比较口径

纯容量填充：从给定初值免费自然等待到首次容量触点 `(s1,K)`，用 `q_B=1-h/s` 维持 `i=K` 直到 `(h,K)`，再置 `q=0`。当 `s1>=s_B` 时，两方案共享前段；最优方案于 `(s_B,K)` 转为 `q=1`，在安全边界 `(s_bar,i_bar)` 停止付费。`T_fill`、`T_star` 仅计算正控制集合的时间测度，不包括免费等待和安全集内延拓。

固定正初值扫描设 `s0=.9999,i0=.0001`，只取 `K>=i0`。`s1<s_B` 时，公共容量尾段比较不适用，CSV 明确标记 mask；总成本、成本差、时长等比较字段留空。图的四个面板均屏蔽这些点，避免把辅助几何上的尾段差当作该初值的最优节省。

高精度 JSON/CSV 数字以十进制字符串输出最多 72 位数字；这只是存储格式，并非对全部 72 位均准确的承诺，实际残差见检查文件。作图数据最后才转换为双精度。DeltaJ 先在 80 位使用 log1p、expm1 与公共尾段成本差计算，不由两个双精度总成本相减。

## 小容量族与误差

独立初值族采用 `s0=1-K/2,i0=K/2`，因此 `s1(K)->s1^circ=1>h`，允许 K 降至 1e-9，不违反正感染初值与容量约束。全部五个 beta 均重算 K=1e-3,...,1e-9。JSON 记录三条展开的误差、二阶退出位置余项/K^3、DeltaJ/K^2、相对节省/K^3 及其极限系数。

## 核对

`analytic_checks.json` 保存一元根残差、端点不变量残差、Theta 匹配残差、公共尾段与总成本差的一致性，以及两个独立容量成本积分核对。五个小容量族均检查末点误差收敛与末三个点的相对节省对数斜率趋近 3。

本轮检查通过：扫描 620 个参数组合；小容量族 35 个组合；独立积分 2 个；阈值 18 个（当前与历史来源各 9 个）。完整过程含标量求根迭代，不属于优化器调用或 OCP 求解。
