# 新增数学内容的核对与依赖

这是本轮新增或展开内容的人工推导检查，不是形式化证明认证，也不是重新声称所有未讨论扩展均已解决。

## 1. 水平集引理

输入仅为绝对连续性；没有控制连续性、有限切换次数或最优性假设。

对固定 E_α={v=α}，非孤立且可微的内点可以取 E_α 内的差商序列，导数为零；孤立点可注入有理端点区间集合，至多可数。绝对连续性保证余下不可微点构成零测集。由 v−u 的零水平集立即得到两函数在可测集合上相等时的导数相等结论。

该引理是对上版横穿证明中已有事实的提取与展开，并非新增的模型假设。

应用已逐项检查：

- 切换界面：只在 s>e 的邻域内复合 χ(x(t))，不在 χ 无定义的区域使用链式法则；先局部化再以可数集合覆盖。
- 容量集合：i(t)=K 时，i'=0 几乎处处，再代入几乎处处成立的状态方程得到 q=q_B。
- 容量迹：b(s)=U(s,K) 在整个 s>0 上局部 Lipschitz，故有限时间内 b(s(t)) 绝对连续；与 u(t)=U(x(t)) 在容量集合上相等，才能应用“两函数”版本。
- 安全集：u(t)=0，在对应时间集合上 u'=0 几乎处处。

本引理本身并不证明“轨道不能离开容量边界”。原唯一性证明的局部开时间区间反证仍保留，没有用水平集性质替代它。

## 2. χ 的正负侧与分区

此处的 χ=i−I_Γ(s) 是切换界面的定义函数，不是 Hamiltonian 中的仿射系数 Σ。两者用途不同，新稿标题避免混称。

仅由既有推论 `cor:Gamma-labels` 得到 φ_Γ(s)=Φ(s,I_Γ(s)) 严格递增及其逆坐标 η_Γ。对 Φ_A<φ≤Φ_B 且 s>e：

    s<η_Γ(φ) ⇔ φ>φ_Γ(s) ⇔ i>I_Γ(s) ⇔ χ>0。

逆向严格不等式和等号同理。继而用已经存在的分区定义识别完全跟踪区、内部切换等待区和切换曲线。没有在这一步调用候选最优性、HJB 或值函数梯度。

两个边缘情况已分别处理：

1. χ>0 且 i≤K 蕴含 I_Γ(s)<K=I_Γ(s_B)，所以 s<s_B。由于 s>e>h，函数 s−h log s 严格增加，进而 Φ(x)≤K+s−h log s<Φ_B。这解决容量切换点之后需要确认 Φ≤Φ_B 的问题。
2. h<s≤e 时，Φ(x)≤K+e−h log e<Φ_B 且 η_Γ(Φ(x))>e≥s，所以不安全点直接属于完全跟踪区。这里没有在 s≤e 定义或求导 I_Γ。

这些限制不是新的参数假设，而是对原公式适用域的明确说明。

## 3. 从横穿到唯一拼接

原几何结论给出 I_Γ'(s)>ℓ/s，使 f₀、f₁ 两端向量场对 χ 的 Lie 导数同时严格为正。连续性和控制区间的紧性（也可直接用两个端点的凸组合）在每个切换点邻域内给出对所有 q∈[0,1] 一致的正下界 δ_*。

沿任意可测控制生成的绝对连续轨道积分，得到

    χ(x(t))−χ(x(t₀)) ≥ δ_*(t−t₀)。

若 x(t₀) 位于切换曲线，则 χ(x(t₀))=0，所以轨道立即进入正侧。新分区引理把“正侧”转换成确切的完全跟踪区域，包括 (s_B,K) 的容量角点。

对最优轨道，此后的验证零残差使 q=1 几乎处处。完全跟踪区域保持引理及对应 ODE 唯一性，确定直到安全集的一整段，并阻止返回等待分支。对从切换曲线出发的候选轨道，使用同一几何方向，不依赖最优性。

D 与 χ 的梯度方向补写也只使用局部几何：D 的光滑延拓存在、两者零曲线有同一切空间、L_{f₁}D<0<L_{f₁}χ，因此 ∇D 是 ∇χ 的负倍数。非零梯度并未通过未证明的 HJB 推出。

## 4. 依赖顺序

    状态适定性 + 水平集基础引理
                  ↓
    完全跟踪正端点 + 单峰性 + 切换曲线几何
                  ↓
    全方向横穿 → χ 与分区对应 → 跟踪区域保持
                  ↓
    候选达到性 → 梯度/拼接/局部 Lipschitz
                  ↓
    轨道验证（统一引用水平集引理）
                  ↓
    有限成本终端引理 + 全局比较
                  ↓
    零残差 + 不可提前离边 + 横穿/分区对应 + ODE 唯一性

新增引理没有反向引用全局最优性或唯一性，因而没有形成循环依赖。原来的一维策略族极小推论仍位于两条主定理之后。

## 5. 时间量词

时变部分没有重新建立 DPP、值函数正则性或一般的验证定理。新的表述明确：当 c 仅可测时，相关经典微分公式只在微分化有效的时间点使用，至多按时间几乎处处理解。

尤其没有把一个状态—时间乘积空间中的 a.e. 等式直接限制到一条可能位于异常集合的曲线上。若将来开展时变全局验证，沿每一条被比较轨道的复合函数链式法则及验证不等式仍须独立建立。

本轮约定的两项基础数学补写和衔接，以及时间量词规范均已写入完整主稿，没有把它们留为未证假设。

主定理的模型范围不变：c、γ 为正常数，0<p<1、0<K<1，正初始状态、s+i≤1、i≤K，控制为 [0,1] 值可测函数，费用为 ∫pcq。没有加入右连续控制相容性推论。
